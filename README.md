Zenith News is a modern, high-performance web application designed to deliver the latest global headlines with an unmatched premium aesthetic. Built with React and Vite, the platform features buttery-smooth micro-interactions, an immersive dark/light mode experience, and a stunning glassmorphic UI.

---

## ✨ Features

- **Premium UI/UX:** A sophisticated design system featuring glassmorphism, dynamic gradients, and elegant typography (Playfair Display & Outfit).
- **Immersive Dark Mode:** Seamlessly toggle between a clean Light mode and a deep, immersive Zinc Dark mode.
- **Fluid Animations:** Powered by Framer Motion, every interaction—from hovering over articles to expanding mobile menus—feels alive.
- **Categorized News:** Browse top stories globally or dive deep into specialized categories (Technology, Business, Science, Health, Sports, Entertainment).
- **Live Search:** Quickly hunt down breaking stories with the integrated keyword search feature.
- **Fully Responsive:** Flawless experience across all devices, with intelligent layouts scaling from mobile screens to ultra-wide monitors.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Data Fetching:** [Axios](https://axios-http.com/)
- **Routing:** [React Router v7](https://reactrouter.com/)

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Karankumar2403/Zenith_News.git
   cd Zenith_News
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your NewsAPI key:
   ```env
   VITE_API_KEY=your_news_api_key_here
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open the app:**
   Visit `http://localhost:5173/` in your browser.

## 📸 Design Philosophy

Zenith News abandons the generic "dashboard" look in favor of a curated, editorial aesthetic. The goal was to build a news application that not only performs at lightning speed but also feels like a luxury reading experience.
